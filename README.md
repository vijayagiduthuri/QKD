## 📌 Overview

Traditional e-auction systems rely on classical encryption, making them vulnerable to interception and tampering.
This project introduces a **quantum-secure solution** that ensures **confidential, transparent, and tamper-proof bidding**.

Built as part of **Amaravati Quantum Valley Hackathon 2025**
Problem Statement ID: AQVH911 

---

## 🧠 Problem Statement

* Classical encryption can be compromised by advanced attacks
* Sensitive bid data can be intercepted
* Lack of transparency reduces trust in auction systems

---

## 💡 Solution

A **Quantum-Secure E-Auction System** that:

* 🔑 Uses **BB84 QKD** to generate secure keys
* 🔒 Encrypts every bid uniquely
* 👁️ Detects eavesdropping using **QBER**
* 🤝 Ensures fairness, trust, and transparency

## 🏗️ System Workflow

1. User Registration / Login
2. Admin Creates Auction
3. Users Join Auction
4. Bidder Prepares Bid
5. 🔐 Encrypt Bid using QKD Key
6. Submit Encrypted Bid
7. Auction Ends
8. Decrypt Bids
9. Reveal Winner
10. Generate Reports & Logs

---

## 🔬 How It Works

* Quantum keys are generated using **BB84 protocol simulation**
* Each bid is encrypted using a **unique quantum-generated key**
* Any interception introduces detectable errors
* Ensures **secure and tamper-proof communication**
